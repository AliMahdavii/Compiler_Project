# فاز اول کامپایلر NovaScript+ (تحلیل لغوی دستی)

اسکنر دستی و جدول‌محور به زبان Python. جدول انتقال DFA از فایل CSV در زمان اجرا خوانده می‌شود و کد هیچ `if/else` یا `switch/case` برای تعیین حالت‌ها ندارد.

## اجرا
نیاز به نصب بسته ندارد (Python 3.8 یا بالاتر).

```text
python ui.py                         رابط گرافیکی
python scanner.py samples/valid.ns   اجرا در ترمینال
python -m unittest -v                اجرای تست‌ها
```
اگر در لینوکس `tkinter` نبود: `sudo apt install python3-tk`. اگر Python با دستور دیگری اجرا می‌شود (مثلاً `python3` یا `py`)، همان را بنویسید.

## فایل‌ها
| فایل | کار |
|---|---|
| `scanner.py` | اسکنر جدول‌محور (حدود ۱۰۰ خط) |
| `transition_table.csv` | جدول انتقال DFA و نوع توکن حالت‌های نهایی |
| `ui.py` | رابط گرافیکی تیره: ویرایشگر رنگی، جدول توکن، جدول DFA، نمودار NFA/DFA، کنسول |
| `test_scanner.py` | ۱۳ تست خودکار |
| `nfa_dfa.md` | عبارت منظم، NFA، ساخت DFA و توضیح CSV |
| `nfa.dot`, `dfa.dot` | منبع شکل‌ها (چاپی، پس‌زمینه‌ی سفید) |
| `diagrams/` | تصویر تیرهٔ NFA و DFA که در رابط نمایش داده می‌شود |
| `samples/` | ۵ برنامهٔ تست: `valid`, `arithmetic`, `identifiers` (بدون خطا) و `invalid`, `errors` (با خطا) |
| `presentation_notes.md` | یادداشت ارائه و سؤال‌های محتمل |

ساخت دوبارهٔ تصاویر پس از تغییر فایل‌های `.dot` (نیاز به Graphviz):
```text
dot -Tpng -Gbgcolor="#161b22" -Gdpi=110 -Gpad=0.3 -Ncolor="#58a6ff" -Nfontcolor="#e6edf3" -Ecolor="#8b949e" -Efontcolor="#e6edf3" dfa.dot -o diagrams/dfa.png
```
(برای `nfa.dot` هم همین‌طور.)

## زبان پشتیبانی‌شده
شناسه (`letter(letter|digit)*`)، عدد صحیح، `+`، `=`، `(`، `)` و کلمات کلیدی `int` و `if`. فاصله، Tab و خط جدید نادیده گرفته می‌شوند. هر کاراکتر دیگر خطای لغوی است و اسکن بعد از آن ادامه پیدا می‌کند.

## محدودیت‌های شناخته‌شده
- **کامنت پیاده نشده است.** صورت پروژه می‌گوید اسکنر باید کامنت‌ها را فیلتر کند. اگر استاد روی این تأکید دارد، باید یک الگوی کامنت (مثلاً `//` تا آخر خط) به NFA و جدول CSV اضافه شود.
- عدد اعشاری و عملگرهای `- * /` نداریم.
- `12abc` به دو توکن `INTEGER` و `IDENTIFIER` تبدیل می‌شود.
